# NewLeaf 🌱

NewLeaf is a personal finance app built with React Native and Expo that helps users budget, track expenses manage debt, and achieve financial goals through a calming, growth inspired experience.

## Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router

## Planned Features

- Budget tracking
- Transaction management
- Debt Garden
- Savings goals
- Supabase backend
